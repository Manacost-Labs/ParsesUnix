# X

**Статус: NOT LIVE VERIFIED.**

## Два отказа, определяющие адаптер

**API выключен по умолчанию.** `XApiConfig.enabled = False`. API дорог и
тарифицируется по уровням, поэтому адаптер, тянущийся к нему автоматически,
может потратить много денег на вопрос, на который ответил бы бесплатный путь.
При выключенном API **пути к нему в коде нет** — не ветка, которая пропускается.

Если API включён, адаптер поднимает `NotImplementedError`, а не откатывается
молча на публичный путь: оператор, включивший API, хочет API, и тихая подмена
ответила бы на другой вопрос.

**Стена авторизации — это ответ, а не препятствие.** При `AUTH_REQUIRED` сбор по
этому URL прекращается. Куки не подставляются, сессия не воспроизводится, адрес
не меняется. Контент за стеной не публичен, и площадка это сказала.

В модуле нет `auth_token`, `ct0`, `guest_token`, работы с `set_cookie` — тест
проверяет отсутствие.

## Путь получения

Обычная лестница маршрутов, та же, что у любой другой цели:

```
публичная страница → L1 → BrowserWorker → Scrape.do → Firecrawl → Bright Data
```

Адаптер не владеет транспортом. Он строит URL поиска, интерпретирует ответ и
нормализует его; решения о маршруте остаются там, где они уже принимаются.

## Что реализовано

| Возможность | Как |
|---|---|
| Поиск | грамматика X: `from:`, `since:`, `until:`, вкладки `live`/`top` |
| Окно времени | **в запросе**, а не фильтром после выборки |
| Дедупликация | по стабильному post ID, никогда по хешу текста |
| Разбор | встроенный JSON, при отсутствии — канонические ссылки `/status/<id>` |
| Провенанс | маршрут, провайдер и стратегия — на каждой сущности |
| Беседы | доступная публично часть, **всегда** помеченная неполной |

Окно времени уходит в запрос, потому что страница результатов, которую мы потом
отбросим, всё равно была отрендерена за наши деньги.

Разбор предпочитает встроенный JSON разметке: классы переименовывают постоянно,
а форма данных меняется куда реже, и селекторный парсер тихо возвращает пустоту
в ту неделю, когда вёрстку переделали.

## Чего адаптер не делает

- Не изобретает `created_at`: на странице поиска его нет, значит поле `None`.
- Не заявляет полноту беседы: публичный вид показывает подмножество ответов, и
  это записано в `completeness`, а не умолчано.

## Ограничения

- Живых вызовов не было.
- Путь через API не реализован.
- Разбор встроенного JSON — по наблюдаемой форме; при редизайне сработает
  запасной путь по каноническим ссылкам.
