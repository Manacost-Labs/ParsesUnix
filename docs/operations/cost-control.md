# Контроль стоимости

## Кто решает платить

Не роутер. Решение о платном уровне принимает **triage** — только по вердиктам
`BLOCKED`/`SOFT_BLOCK` — и оно проходит через бюджет. Провайдерский роутер
отвечает на другой вопрос: *«раз платить разрешено, какой стратегией?»*

## Задача роутера

```
минимизировать ожидаемую стоимость
при условии  надёжность >= целевой
```

Надёжность — нижняя граница Уилсона по **валидированным** успехам конкретной
стратегии. Не по провайдеру целиком: провал `normal` на домене ничего не говорит
о том, сработает ли там `super`.

## Порог надёжности — это НЕ доля успехов

Сравнение идёт с *пессимистичной* нижней границей. При идеальной истории:

| Наблюдений | Нижняя граница |
|---:|---:|
| 10/10 | 0.722 |
| 20/20 | 0.839 |
| 40/40 | 0.912 |
| 70/70 | 0.948 |
| 200/200 | 0.981 |

Отсюда практический вывод: **порог 0.95 требует около семидесяти подряд
валидированных успехов**. Поставив его «для надёжности», вы получите роутер,
который отказывает всем стратегиям. По умолчанию — `0.80`, достижимо примерно с
15 чистых наблюдений; поднимать точечно для тех классов URL, которые этого
действительно заслуживают.

## Стратегия должна отвечать на проблему

Платить за возможность, которая не лечит наблюдаемый отказ, — самый быстрый
способ потратить бюджет впустую.

| Возможность | Отвечает на | Не отвечает на |
|---|---|---|
| премиальная сеть (`super`) | `BLOCKED`, `SOFT_BLOCK` | `CSR_REQUIRED`, `PARSE_FAIL`, `ORIGIN_DOWN` |
| рендеринг (`render`) | `CSR_REQUIRED`, `SOFT_BLOCK` | `BLOCKED`, `DEAD_URL`, `ORIGIN_DOWN`, `PARSE_FAIL` |

Жёсткий `403` рендерингом не пробивается: WAF откажет и отрендеренному запросу, а
стоить это будет впятеро дороже.

## Резервация бюджета

Гонка не внутри записи расхода, а между проверкой и самим вызовом: N воркеров
проходят проверку и все тратят. Поэтому кредиты **резервируются до вызова**:

```
reserve(estimate)   ->  держим кредиты, лимит проверяется здесь
   вызов провайдера
settle(actual)      ->  запись фактической стоимости из заголовка
release()           ->  вызова не было, ничего не списано
```

Проверено: 20 потоков при лимите 10 кредитов дают ровно 10 разрешённых, 10
отказов и ноль зависших резерваций.

## Стоимость, которую не удалось определить

Если провайдер не сообщил стоимость, вызов помечается `unattributed` и считается
**не бесплатным**. Молча обнулённый расход — это как превышают бюджет.

## Объяснимость

Любое платное решение печатается:

```
provider: scrape.do
escalation verdict: BLOCKED
reliability target: 0.800
   normal        cost   1  reliability 0.000  0/20 validated, below target 0.800
   render        cost   5  reliability 0.000  rendering does not address BLOCKED
-> super         cost  10  reliability 0.839  20/20 validated
```
