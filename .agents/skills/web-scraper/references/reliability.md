# Надёжность доступа, извлечения и записи

## 1. Доступ

До подъёма уровня перебрать разрешённые альтернативные маршруты: API, RSS/Atom, sitemap, JSON-LD, AMP, мобильную или print-версию, oEmbed. Каждый маршрут имеет собственную схему извлечения и метрику качества. Усечённый маршрут помечать `degraded`, а не `OK`.

Для сайта, требующего сессию, прогреть её главной/родительской страницей, сохранить cookies локально только на время разрешённой задачи и не передавать их провайдеру. После первого `BLOCKED` считать сессию отравленной и пересоздать.

## 2. Извлечение

Порядок экстракторов:

1. JSON-LD/schema.org.
2. `__NEXT_DATA__` и другое сериализованное состояние.
3. Microdata/OpenGraph/meta.
4. CSS/XPath.
5. Эвристики текста.
6. Ручное восстановление по сохранённому снапшоту; LLM использовать только как помощника, не как безусловный источник истины.

Для 3–5 критичных полей применять независимый кворум. Расхождение не разрешать молча: отправлять запись в staging с `conflict`.

Нормализовать даты с таймзоной, числа/валюты, пробелы, HTML entities и относительные URL до валидации.

## 3. Полнота обхода

- Сверять собранное количество с заявленным счётчиком или sitemap.
- Дедуплицировать по натуральному ID; повтор курсора/ID ловит цикл пагинации.
- Ограничивать глубину и сигнализировать о достижении лимита.
- Несколько пустых страниц подряд не считать концом без независимого подтверждения.

## 4. Запись

```text
STAGING -> VALIDATE -> ATOMIC PROMOTE
                      -> reject: clean/LKG stays unchanged
```

Проверять схему, диапазоны, обязательность, null-rate, объём и согласованность связанных наборов. При провале не публиковать частичный прогон. Сохранять staging и сырой снапшот для разбора.

Ключ идемпотентности: натуральный ID или нормализованный URL плюс хэш нормализованного содержимого. Повтор окна не создаёт дублей и не переписывает неизменившееся.

URL, который не получен ни одним разрешённым маршрутом после нескольких прогонов, помещать в `dead_zones` с историей вердиктов. Это дефект покрытия, а не обычный 404-карантин.
