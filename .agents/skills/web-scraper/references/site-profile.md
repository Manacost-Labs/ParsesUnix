# Site Profile

Site Profile хранит решения для домена декларативно и не содержит секретов.

Обязательные группы:

- классы URL и правила нормализации;
- целевые поля и выходная схема;
- канарейка, минимальный размер и стоп-сигнатуры;
- основной и альтернативные маршруты;
- порядок экстракторов и quorum fields;
- политика сессии и пагинации;
- лимиты конкуренции, retry и paid budget;
- freshness window и правила promote.

Скопировать `assets/templates/site-profile.yaml` и удалить неприменимые секции. Не добавлять API-ключи, cookies, токены и персональные данные.

Перед продом проверить профиль на нескольких страницах каждого URL-класса, включая старую, новую, удалённую, редирект, пустой результат и страницу с изменённой разметкой.
