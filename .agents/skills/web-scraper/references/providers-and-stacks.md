## Python

Scrapling — дефолт для нового Python-парсера: HTTP fetcher/sessions, браузерный fetcher, stealth-режим, spiders, чекпойнты и adaptive parsing. Установку и точные имена API брать из официальной документации и официального agent-skill:

- https://scrapling.readthedocs.io/
- https://github.com/D4Vinci/Scrapling/tree/main/agent-skill/Scrapling-Skill

Не копировать полный официальный Scrapling skill в этот проект: использовать его как актуальный API-reference, а этот скилл — как архитектурный слой triage, стоимости и надёжности.

Scrapy оставлять для существующих проектов или специфичных расширений. Старые советы про `cloudscraper`, `cfscrape`, FlareSolverr и JS-only stealth-плагины не принимать без актуальной проверки.

## Rust

Для L1 использовать актуальный `wreq`/`wreq-util`, а не устаревшее имя `rquest`; HTML разбирать `scraper`, асинхронность — `tokio`. Проверять текущие release/feature flags:

- https://github.com/0x676e67/wreq

Не собирать рядом BoringSSL и `openssl-sys` без проверки конфликтов символов. Браузерный L2 обычно оставлять в Python.

## scrape.do

Официальные страницы:

- https://scrape.do/documentation/
- https://scrape.do/documentation/request-costs/

Подтверждено на дату review:

- `2xx`, `400`, `404`, `410` могут списывать кредиты;
- доменный профиль может изменить фактическую стоимость независимо от переданных параметров;
- источником истины для расхода служит `Scrape.do-Request-Cost`;
- встроенные ретраи нужно согласовать с собственным retry budget, чтобы не получить двойные повторы.

Поэтому 404/410 необходимо отсеивать до платного канала, а расход учитывать по заголовку.

## Firecrawl

Использовать, когда нужен его текущий crawl/map/markdown/structured workflow, а не просто HTML. Перед кодом проверить форматы, множители, лимиты, кэш/freshness и поведение очереди:

- https://docs.firecrawl.dev/
- https://www.firecrawl.dev/pricing

Любой ответ с усечёнными или невалидными обязательными полями классифицировать по данным, а не по зелёному статусу задания.

## Bright Data Unlocker

Использовать как дорогой поздний fallback для разрешённых публичных данных:

- https://docs.brightdata.com/scraping-automation/web-unlocker/

Подтверждено на дату review: включение Custom Headers & Cookies меняет оплату на все попытки, включая неуспешные. Запретить эту настройку по умолчанию; требовать явное одобрение, отдельный низкий бюджет и проверку комплаенса. Не передавать аутентификационные cookies.
